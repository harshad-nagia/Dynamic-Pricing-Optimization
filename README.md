Dynamic Pricing & Demand Optimization Model

Overview
This project is a data-driven pricing simulation model designed to analyze the impact of price changes on product demand and overall profitability. By bridging machine learning with business strategy, this tool allows stakeholders to identify the exact price point that maximizes revenue without sacrificing consumer demand. 

Business Impact
* Revenue Maximization: Identifies the mathematical peak of profitability (the optimal price) using elasticity curves.
* Risk Mitigation: Simulates worst-case and best-case scenarios for pricing strategies before implementation.
* Strategic Decision Making: Translates raw sales data into actionable financial projections.

Tech Stack
* Python: Data generation and logic
* Libraries: Pandas, NumPy, Scikit-Learn, Matplotlib
* Microsoft Excel: Interactive scenario dashboard and financial forecasting

Methodology
1. Data Processing
Analyzed a dataset of 3,000+ retail sales records. The data was processed using Python and Pandas to clean and format the pricing and quantity metrics for statistical analysis.

2. Elasticity Modeling
Built a Log-Log Linear Regression model using Scikit-Learn to calculate the Price Elasticity of Demand (PED). This machine learning model determined exactly how sensitive the product's demand is to price fluctuations.

3. Scenario Simulation
Exported the mathematical model parameters into an interactive Microsoft Excel dashboard. This tool projects new demand, total revenue, and profit margins dynamically based on hypothetical percentage price changes.

### 4. Visualization
Generated an inverted-U profit curve mapping simulated prices against projected total profit to visually pinpoint the optimal pricing strategy.
